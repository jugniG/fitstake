# Exercise illustrations

The push-up frames in `push-up/` come from **Workout Guide** by Bryl Lim
(https://github.com/bryllim/workout-guide), based on original pose artwork by **Everkinetic**.
They are licensed under **CC BY-SA 4.0** (https://creativecommons.org/licenses/by-sa/4.0/).

Changes made here: the fill colour was changed from white (`#fff`) to StakeFit navy
(`#0d1b2a`) so the drawing shows on a light background.

These SVGs are copied from the repository's `packages/workout-guide/assets/push-up/` because
the npm release (`@bryllim/workout-guide@1.0.0`) only ships PNG versions. Once a release with
the SVGs is published, import them from the package instead and delete this folder.
